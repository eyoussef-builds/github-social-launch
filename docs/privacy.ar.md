# الخصوصية وتأثير النشر الحقيقي

[English](privacy.md) · [الدليل الرئيسي](../README.ar.md)

## الحزمة العامة

يحتوي المستودع تعليمات قابلة لإعادة الاستخدام، وقوالب فارغة للتفضيلات وسجل الحملة، وأمثلة تفكير مخترعة، وأدلة باللغتين وصورًا ترويجية عامة. لا يحتوي المحادثات الأصلية أو بيانات الحسابات أو الحملات الحقيقية أو المستلمين أو صور الإثبات الخاصة. التواصل المعتمد هو `eyoussef-builds` و`hello@eyoussef.me` و`eyoussef.me`.

تم تعميم الخطوات من طريقة عمل حقيقية دون نشر أدلتها الخاصة. مسارات مثل `~/.agents/skills/` تشرح أماكن عامة لحساب المستخدم، وليست تفاصيل جهاز المؤلف. المهارة تعليمات فقط، دون قاعدة حسابات مخفية أو إضافة متصفح أو برنامج جدولة تنفيذي أو مخزن مفاتيح.

## حالة عملك الخاصة

احفظ `references/local-profile.md` المثبت وسجل الحملة المملوء ومعرّفات المنشورات وروابط الإدارة والحسابات وحالة المتصفح وصور الجداول والمستلمين خارج المستودعات والإصدارات العامة. القوالب الفارغة نقطة بداية؛ بعد تعبئتها تصبح سجلات تشغيل خاصة. `.gitignore` مساعدة فقط ولا يحمي ما سبق حفظه في السجل أو إضافته بالقوة.

استخدم المتصفح المسجّل دخوله أو أداة متصلة مسموحًا بها عبر الأدوات المدعومة للمساعد. لا تصدّر Cookies أو بيانات الدخول أو Tokens لتشغيل الأتمتة. تحقق من الحساب والوجهة الفعليين، لا من رقم قديم أو مثال يخص شخصًا آخر.

## أين تنتقل البيانات؟

- يعالج نموذج المساعد معلومات المستودع وأدلة العمل التي يقرأها حسب إعدادات الخدمة.
- تستقبل خدمة الصور الوصف والمراجع. استخدم صورًا عامة معتمدة، دون لوحات خاصة أو رسائل.
- ترفع الجدولة النص والصور المختارة إلى المنصة والحساب المحددين، وقد تنشرهما المنصة لاحقًا تلقائيًا.
- ضبط قاعدة تعليقات مأذون بها يجهّز ردودًا ورسائل مستقبلية لمن يفعّلها ضمن القناة والنطاق المحفوظين. راجع الأثر قبل الحفظ.
- تسليم العمل لمحادثة أخرى يرسل نص التسليم ومراجع الملفات لتلك المحادثة عند وجود الإذن، ولا يأذن بردود أو رسائل أو إجراءات أخرى غير مرتبطة.

لا تدّعي المهارة أن كل المعالجة دون اتصال. تجهيز الملفات وحده لا ينشر ولا يرسل؛ الجدولة وتغيير قواعد الرسائل يحتاجان الإذن والصلاحيات المناسبة.

## راجع وبلّغ بدقة

افحص النص والكلمة والرابط والصورة والحساب والتاريخ المحلي قبل الإرسال. راجع القوائم الحقيقية وافتح القواعد بعد حفظها. القاعدة المفعلة ليست اختبار وصول رسالة، والمسودة ليست مجدولة، والمجدول ليس منشورًا بعد. احتفظ بالأدلة الخام خاصة وامنح المستخدم إثباتًا محليًا مفيدًا.

عند نشر هذه المهارة أو نسختك، صدّر الملفات القابلة لإعادة الاستخدام فقط إلى حزمة نظيفة مراجعة. استبعد الملفات الشخصية والسجلات الحقيقية والتاريخ الخاص. افحص الصور وبياناتها والملفات وأسماء الأرشيف وهوية Git والسجل قبل النشر وبعده. إرشادات الخصوصية ليست ضمانًا لإخفاء كل معلومة ممكنة.
