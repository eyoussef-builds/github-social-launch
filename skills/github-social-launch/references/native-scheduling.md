# Native scheduling: Meta and LinkedIn

Discover controls from the current accessible UI. The method below describes a workflow, not fixed selectors or a guarantee that every account has every feature. Use the host's supported browser/computer API; inspect fresh UI state after actions. Do not reuse numeric accessibility indices, checkbox positions or frame URLs copied from another session.

## Before composing

Confirm the user-selected browser and signed-in account. Reuse the specified Edge/Chrome/etc session when requested. Do not infer the correct Page from the logged-in person's name, an ad account or the first asset in a list. Record the exact target privately. Reading a Page does not prove permission to schedule it.

Inspect existing queues first. Keep one draft at a time per composer so a later image/caption cannot land in another project's draft. Prepare captions and durable final images locally before opening the composer; check file existence and actual dimensions. Do not upload source chats, private screenshots or workspace folders.

## Meta Business Suite

1. Open the intended business/Page's organic Content/Planner area, using a discovered URL or UI. Confirm the Page and connected Instagram account. Ads Manager and catalog tools are not substitutes.
2. In Create post, explicitly select the requested Facebook/Instagram destinations. When adding a missing channel to an existing launch, select only the missing destination. Closing a dropdown can reset its selection; inspect it again.
3. Fill the destination-appropriate caption, attach the correct final image through the supported upload control, and verify the image/preview. Confirm both channel previews when scheduling jointly.
4. Set the future date and time. Some UIs use segmented hour/minute/meridiem controls; navigate through their supported keyboard or semantic controls, then read back every segment. Use the calendar if direct text entry does not persist. Confirm the actual date, not just a weekday.
5. Inspect identity, selected channels, caption, attached image and schedule together before submission. Submit Schedule. Preserve a draft if temporarily unable to finish, and record its actual status.
6. Open/reload Scheduled content and verify each selected channel's entry with date/time, caption and artwork. A mixed Meta queue can hide a missing channel; inspect filters or per-channel detail. Decline/dismiss optional boost prompts without changing delivery to an ad.

## LinkedIn personal profile

Confirm the posting actor is the intended personal profile and the selected audience is within the user's scope. Use Start a post, add the caption/image, complete any media-preview Next step and open the clock/scheduling control shown in that UI. Select date/time, apply Next/confirmation, and verify the schedule remains displayed above the final composer. Final submission must schedule rather than post now.

Reopen View scheduled posts/the current equivalent. Match the saved caption, image and exact timestamp. Keep a user-requested one-per-day cadence even when a different time is free. Do not overwrite or delete another scheduled post to make room.

## LinkedIn Page

Verify the organization Page and appropriate admin/content view separately from the personal profile. Use Page posts and its own composer/queue. If the admin UI renders in a frame, inspect the actual frame/accessible content and use the supported frame API; do not guess a remembered iframe URL or manipulate hidden page internals.

Attach the correct image and caption, choose the schedule, and inspect the final date/time and posting identity before submitting. Reopen the Page's scheduled queue independently. A saved draft is not scheduled; a scheduled personal post does not establish that the Page version exists. Handle the Page's current time-window validation rather than relying on the profile's limits.

## Troubles and proof

If an action has no effect, inspect the actual blocker/state before retrying. If save/upload times out, reconcile the live queue before another submission. Stop on login/security challenges according to the host's policy; do not bypass restrictions, purchase upgrades or export cookies/tokens. Complete independent destinations and preserve concrete drafts when one channel is unavailable. Keep final schedule screenshots and useful object references private, then report true per-destination results.
