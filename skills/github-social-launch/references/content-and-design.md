# Content and visuals for a repo launch

Read actual repository facts first: README, Arabic README when present, latest release and license. Inspect relevant code/docs to establish stack/platform claims; distinguish released capabilities from plans. If source access fails, request the needed text instead of inventing it. Use the user's supplied motivation without fabricating personal stories, metrics, users, pricing or results. Public source visibility is not an open-source license. Free skill code does not make its model/API/image services free.

Use [the Arabic writing recipes](social-posts.md) for the four copyable blocks. Add a separate Instagram caption only when selected. Reuse the Facebook caption if it fits the current Instagram composer and reads well there; otherwise shorten it while keeping essential benefits, costs/requirements, the exact comment keyword and brand. Validate against the actual platform's current constraints rather than assuming that a long Facebook caption will fit. Preserve the keyword and accurate hashtag selection across channels. Keep Facebook/LinkedIn URLs out of the actual caption blocks in this recipe; the reply/DM carries the link. Do not accidentally paste source URLs, evidence notes or Markdown fences into a composer.

When the package is already approved, reuse its matching social artwork. Check exact keyword, actual dimensions/crop, Arabic shaping, real product name and private details. An explanatory infographic is not automatically the best promo cover; prefer a clear headline, short useful result, genuine public repo/product insert and readable CTA. Avoid drawing fake app interfaces for a skill. Use the image-generation tool and its skill for requested raster creation/edits, preserving existing approved content when only making a targeted correction.

Default brand direction: cream `#FAF8F2`, yellow `#FFE04A`, ink `#15130F`, readable modern Arabic/English type, generous margins and a black CTA panel with yellow/cream text. Prefer portrait 4:5 around 1080×1350, but verify actual exported dimensions and each platform preview; never claim an exact size without checking it. Keep genuine screenshots' own colors intact. Yellow hearts 💛 are the default for this brand in captions, comments and messages; another user's explicit brand overrides it.

Save final images durably before uploads. Inspect actual pixels and metadata for private account menus, notifications, IDs, source paths and unrelated material. Public skill explainers may use synthetic generic illustrations; actual campaign evidence/screenshots stay private. Keep public marketing assets and private scheduling evidence in separate folders/manifests.
